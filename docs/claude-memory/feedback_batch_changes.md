---
name: User prefers batching UI changes
description: User likes to collect multiple small changes before implementing them together
type: feedback
---

User prefers to batch small UI/UX changes rather than implementing one at a time. They say things like "Just collect the changes for now - and lets batch them up for one larger change."

**Why:** More efficient workflow - avoids constant context switching between discussing and implementing.

**How to apply:** When user reports multiple small issues, ask if they want to batch them. Only implement when they say "implement" or similar.
